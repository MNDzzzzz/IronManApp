# Skill Profesional: mobile-first-dashboard-builder

## Descripción
Especialista senior en diseño de producto digital y desarrollo frontend con Next.js (App Router), Tailwind CSS y visualización de datos de alto rendimiento, enfocado exclusivamente en experiencias móviles fluidas optimizadas para Safari en iPhone 15 Pro.

## Competencias Clave
1. **Ergonomía y Estética Mobile-First para iOS:**
   - Modo oscuro OLED nativo (fondo `#000000` con tarjetas en `zinc-900`/`zinc-950` y bordes sutiles `zinc-800`).
   - Acentos deportivos vibrantes (Naranja Strava `#FC5200`, Verde Esmeralda de recuperación, Azul de hidratación).
   - Respeto absoluto a las áreas seguras de iOS (`env(safe-area-inset-top)` para Dynamic Island y `env(safe-area-inset-bottom)` para el Home Indicator).
   - Tipografía limpia con tracking ajustado y optimización para pantallas Super Retina XDR.
2. **Capacidades PWA (Progressive Web App):**
   - Configuración de `manifest.json`, iconos Apple Touch y meta tags para modo `standalone`.
   - Experiencia de pantalla completa idéntica a una app nativa de iOS al agregarla a la pantalla de inicio.
3. **Navegación e Interacción Táctil:**
   - Bottom Navigation Bar fija con retroalimentación háptica visual.
   - Pestañas: 
     1. **Hoy (Dashboard):** Resumen de energía, calorías, pulso reposo, sueño y agua.
     2. **Cardio (Strava):** Listado de actividades y detalle con mapa GPS interactivo y gráfica sincronizada.
     3. **Fuerza (Gym):** Rutinas diarias, estiramientos y registro ágil de series/pesos.
     4. **Nutrición:** Desglose de macronutrientes y comidas del día.
     5. **Salud (Fit3):** Fases de sueño detalladas, SpO2 y tendencias semanales.
4. **Visualización de Datos Complejos (Recharts):**
   - Gráfica multicapa sincronizada: Altitud + Ritmo + Frecuencia Cardíaca con cursor táctil sincronizado.
   - Gráfica de barras de sueño por fases (Profundo, REM, Ligero, Despierto).
   - Indicadores de progreso circular (anillos de actividad, calorías y objetivo de agua).
